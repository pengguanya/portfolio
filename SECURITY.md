## Security Policy

### Supported Versions

This is a personal portfolio website. Security updates are applied as needed.

### Reporting a Vulnerability

If you discover a security vulnerability, please report it by emailing [guanya.peng@outlook.com](mailto:guanya.peng@outlook.com).

Please include:
- A description of the vulnerability
- Steps to reproduce the issue
- Potential impact

I will respond to security reports within a reasonable timeframe.
